# @ewanc26/tid

Zero-dependency AT Protocol TID (Timestamp Identifier) generation. Works in Node.js 20+, Deno, Bun, and browsers.

```bash
pnpm add @ewanc26/tid
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/tid)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/atproto`](../atproto) — AT Protocol service layer.
- [`@ewanc26/utils`](../utils) — Shared utility functions, zero runtime dependencies.
- [`@ewanc26/tangled-sync`](../tangled-sync) — Sync GitHub repos to Tangled with ATProto records.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
