# @ewanc26/ui

Svelte UI component library — layout components, cards, UI primitives, SEO helpers, stores, and a multi-theme configuration system.

```bash
pnpm add @ewanc26/ui
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/ui)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/utils`](../utils) — Shared utility functions, zero runtime dependencies.
- [`@ewanc26/atproto`](../atproto) — AT Protocol service layer.
- [`@ewanc26/og`](../og) — Dynamic OpenGraph image generation with noise backgrounds.
- [`@ewanc26/svelte-standard-site`](../svelte-standard-site) — SvelteKit library for `site.standard.*` longform records.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
