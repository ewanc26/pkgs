# @ewanc26/noise

Deterministic value-noise generation from a string seed — arbitrary dimensions, multi-octave FBM, multiple colour modes. Zero dependencies.

```bash
pnpm add @ewanc26/noise
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/noise)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/noise-avatar`](../noise-avatar) — Noise-based avatar generation from a string seed.
- [`@ewanc26/og`](../og) — Dynamic OpenGraph image generation with noise backgrounds.
- [`@ewanc26/ui`](../ui) — Svelte UI component library.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
