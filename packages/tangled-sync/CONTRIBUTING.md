# Contributing to tangled-sync

CLI for syncing GitHub repositories to Tangled. It lives in the [ewanc26/pkgs](https://github.com/ewanc26/pkgs) monorepo.

Start with the [root contributing guide](../../CONTRIBUTING.md) for the workflow common to every package: development setup, commit style, the checks expected before opening a pull request, and the licence terms for contributions.

## Notes for this package

- This one uses npm (`package-lock.json`), not pnpm — install dependencies with `npm install` rather than from the pnpm workspace.
- See [SETUP.md](SETUP.md) and [USAGE.md](USAGE.md); if behaviour changes, update both alongside the code.
