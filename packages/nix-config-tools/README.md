# nix-config-tools

Four Rust utilities for managing the nix config — `health-check`, `flake-bump`, `gen-diff`, `server-config`. Run via the flake, no cargo build required.

```bash
nix run github:ewanc26/pkgs#health-check
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/nix-config-tools)**.
