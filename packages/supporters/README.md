# @ewanc26/supporters

SvelteKit component library for displaying Ko-fi supporters and GitHub Sponsors, backed by an ATProto PDS.

```bash
pnpm add @ewanc26/supporters
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/supporters)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/ui`](../ui) — Svelte UI component library.
- [`@ewanc26/atproto`](../atproto) — AT Protocol service layer.
- [`@ewanc26/svelte-standard-site`](../svelte-standard-site) — SvelteKit library for `site.standard.*` longform records.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.

## Support

This is free and open source, built and maintained in my spare time. If it's useful to you, a [one-off tip on Ko-fi](https://ko-fi.com/ewancroft) or a [monthly sponsorship](https://github.com/sponsors/ewanc26) helps keep it maintained. A star on the repo or a mention to someone who'd use it helps just as much.
