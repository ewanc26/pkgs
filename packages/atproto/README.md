# @ewanc26/atproto

AT Protocol service layer — identity resolution, record fetching, Bluesky posts, Standard.site documents, music/mood status, and more.

> **Trademark notice:** `@ewanc26/atproto` is an independent package and is not
> affiliated with or endorsed by Bluesky Social PBC. See the repository's
> [trademark notice](../../TRADEMARKS.md).

```bash
pnpm add @ewanc26/atproto
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/atproto)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/tid`](../tid) — Zero-dependency AT Protocol TID generation.
- [`@ewanc26/utils`](../utils) — Shared utility functions, zero runtime dependencies.
- [`@ewanc26/svelte-standard-site`](../svelte-standard-site) — SvelteKit library for `site.standard.*` longform records.
- [`@ewanc26/ui`](../ui) — Svelte UI component library.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
