# @ewanc26/wafrn-theme

A [WAFRN](https://wafrn.net) theme using the pds-landing Catppuccin terminal aesthetic — dark forest-green palette, JetBrains Mono, soft rounded cards.

Paste the contents of `src/theme.css` into the WAFRN theme editor at **Settings → Theme**.

## Related projects

Other packages in this monorepo:

- [`pds-landing`](../pds-landing) — Terminal-aesthetic landing page for an ATProto PDS.
- [`@ewanc26/ui`](../ui) — Svelte UI component library.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
