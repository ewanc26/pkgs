# @ewanc26/pds-landing

Composable Svelte 5 components for an ATProto PDS landing page — terminal aesthetic, live status fetching, zero config to drop in.

```bash
pnpm add @ewanc26/pds-landing @ewanc26/ui
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/pds-landing)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/wafrn-theme`](../wafrn-theme) — WAFRN CSS theme in the same Catppuccin terminal aesthetic.
- [`@ewanc26/ui`](../ui) — Svelte UI component library.
- [`@ewanc26/supporters`](../supporters) — Ko-fi and GitHub Sponsors supporter display, backed by ATProto.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
