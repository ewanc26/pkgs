# @ewanc26/utils

Shared utility functions — date formatting, number formatting, URL utilities, validators, text helpers, and RSS generation. Zero runtime dependencies.

```bash
pnpm add @ewanc26/utils
```

Full documentation at **[docs.ewancroft.uk](https://docs.ewancroft.uk/projects/utils)**.

## Related projects

Other packages in this monorepo:

- [`@ewanc26/tid`](../tid) — Zero-dependency AT Protocol TID generation.
- [`@ewanc26/atproto`](../atproto) — AT Protocol service layer.
- [`@ewanc26/ui`](../ui) — Svelte UI component library.

Also worth a look: [croft.click](https://croft.click) — free, browser-based tools for moving your data onto the AT Protocol.
