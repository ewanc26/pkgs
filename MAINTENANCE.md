# Maintenance and support

I build and maintain these packages and the croft.click tools in my spare time. This page sets out what you can expect from me, so nobody is surprised.

## Tool status

Each hosted tool is in one of three states.

- **Active.** I fix bugs, keep up with changes in the services it talks to, and may add features.
- **Maintenance.** It stays up and I fix serious bugs and security problems when I can. No new features.
- **Archived.** The hosted version may be taken down. The source stays here under the AGPL for anyone to run.

A tool can move between states when keeping it going stops being sustainable. I'll say so before taking a hosted tool down.

## Issues and requests

Opening an issue doesn't mean it will be implemented. I may decline a feature request or mark it `wontfix`, and an issue labelled `help wanted` is one I'd welcome a pull request for. Keeping up with third-party APIs (Last.fm, Spotify, Instagram exports and so on) is done as time allows, so a break caused by someone else's change may take a while to fix.

All of this is best effort unless a paid support arrangement says otherwise. Paying for the hosted service, when that exists, covers using the hosted service. It doesn't include custom development or guaranteed support unless that's explicitly offered.

## Self-hosting

The software is AGPL-3.0-only. You can run it yourself without paying me or asking permission, as long as you follow the licence. Tips through Ko-fi or GitHub Sponsors are voluntary and separate from anything you buy.
